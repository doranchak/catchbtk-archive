catchBTK.com - reconstructed from Wayback Machine snapshots
=========================================================

Open index.html in a browser (no server needed). Keep this folder inside the same parent folder as the forum post archive (that folder's index.html, i.e.
../index.html from here): links to the discussion board open that local post archive.

- Each page shows its most recent capture. The "History" pill at the bottom of every page opens a slider
  of older versions - only versions whose content differs are listed.
- "Keep this date when I follow links" browses the whole site as it was on a chosen date.
- sitemap.html lists every page, its versions and anything that could not be recovered.
- history/ holds the older versions; _site/ holds the history bar's script and data.

Built from snapshots dated 20040607 - 20061105 (the later captures of this domain are unrelated parked/spam pages and were excluded).
Changes made for offline use: ad frames, the live-chat applet, the PayPal donation form and the right-click blocker were disabled;
text was converted from Windows-1252 to UTF-8.
